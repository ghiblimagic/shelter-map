# Pawlytics

C# WPF geospatial analytics app using Esri ArcGIS Runtime SDK.

Visualizes intake, euthanasia, and live outcome statistics across six LA animal shelters.

## Stack
- C# / WPF
- ArcGIS Runtime SDK
- Python (PDF ETL)
- JSON data pipeline
